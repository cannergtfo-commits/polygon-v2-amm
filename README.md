# Polygon V2 AMM / BlazarSwap

Uniswap V2-style constant-product DEX for **Polygon PoS (chain 137)**.

- Swap fee: **0.30%**
- Protocol fee: **0.05%** to `0x6F47aa396215ab22647dDB3E86b4663DFe11dB14`
- Base token: BlazarBits `0x462D8d82C2B2D2DDabf7f8a93928De09d47A5807`
- Live UI: https://cannergtfo-commits.github.io/polygon-v2-amm/

Public repo: https://github.com/cannergtfo-commits/polygon-v2-amm

## Frontend

Hosted from `docs/` on GitHub Pages.

If the URL 404s, open **Settings → Pages** and set Source to **GitHub Actions**, then rerun the **Deploy GitHub Pages** workflow.
