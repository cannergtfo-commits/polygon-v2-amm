Local prototype · not a hosted bot

Integrate against the source

GitHub Pages is a static site. It does not run the Next.js quote route or the MCP process. Run those on your own machine. The kit does not hold a seed, does not sign, and does not broadcast.

The OpenAPI document is blazar-bot-v1.yaml. Schema blazar.bot.v1. In the source tree the same file is web/public/openapi/blazar-bot-v1.yaml.

Run the local connector

cd web
pnpm install
pnpm exec tsx scripts/mcp-stdio.ts
{
  "mcpServers": {
    "blazarswap": {
      "command": "pnpm",
      "args": ["exec", "tsx", "scripts/mcp-stdio.ts"],
      "cwd": "web"
    }
  }
}

This is a local stdio process. It is not a published plugin and it is not registered. The tools search tokens, explain the fee, and quote. They do not accept an arbitrary RPC URL or an account-wide approval.

Fees, units, and the chart

  • Chain 137. Amounts are base units. 2 POL is 2000000000000000000. BZB and POL use 18 decimals.
  • POL and WPOL are the same asset after wrapping. Do not quote them against each other.
  • The wrapper fee is 0.05% of external principal, charged once. A Blazar factory leg pays 0 wrapper fee. Pool fees are already inside the quoted output. On 10,000 base units the external wrapper fee is 5 and the Blazar factory wrapper fee is 0.
  • The chart scores one pool as 0.70 * normalized liquidity + 0.30 * normalized age. That choice does not restrict the route.
