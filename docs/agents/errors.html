Error codes

Every error from the Blazar Polygon plugin is {code, error, hint, retryable, retryAfterMs?, docs}. Retry only when retryable is true, after retryAfterMs. Never blind-retry a sent transaction: check blazar_tx_status first.

RATE_LIMITED retryable, after 10000 ms

This endpoint's per-IP limit (60 requests/min) was hit. Next: Wait retryAfterMs, then retry. Batch reads into fewer calls.

UPSTREAM_RATE_LIMITED retryable, after 2000 ms

A keyless upstream (KyberSwap or Velora aggregator API) returned 429. Next: Wait retryAfterMs and retry, or pass provider to use the other aggregator.

AGGREGATOR_UNAVAILABLE retryable, after 3000 ms

Neither KyberSwap nor Velora returned a usable route right now. Next: Retry shortly. For BZB use blazar_quote / blazar_build_swap, which read pools onchain.

INTERNAL retryable, after 1000 ms

Unexpected error, usually a public RPC timing out or rate-limiting. Next: Retry once. If it repeats, set BLAZAR_RPC_URLS (local server) or slow down.

UPSTREAM retryable, after 2000 ms

An upstream API failed. Next: Retry shortly.

TX_PENDING retryable, after 4000 ms

The transaction is known but not mined yet. Next: Poll blazar_tx_status again after retryAfterMs. Do not re-send.

TX_NOT_FOUND retryable, after 5000 ms

The RPC does not know this hash (not broadcast, dropped, or not propagated yet). Next: Poll again. Before re-sending anything, compare the latest and pending nonce (pass from).

SLIPPAGE_EXCEEDED retryable, re-quote or rebuild

Price moved past the minimum output. Next: Re-quote and rebuild; trade smaller or raise slippageBps (max 300).

DEADLINE_EXPIRED retryable, re-quote or rebuild

The deadline passed before the tx was mined. Next: Rebuild and sign within the deadline.

DEADLINE_TOO_FAR not retryable

Deadline more than 3 minutes ahead (fee router rule). Next: Rebuild with deadlineSeconds <= 180.

BAD_ROUTE retryable, re-quote or rebuild

Route is invalid for current reserves. Next: Re-quote, then rebuild.

SIMULATION_FAILED retryable, after 2000 ms

The eth_call simulation failed for a reason that is not decoded. Next: Re-quote and rebuild once. If it fails again, do not sign.

SIMULATION_UNAVAILABLE not retryable

This token's storage layout could not be overridden for a simulation. Next: Send the approve first, then run blazar_simulate_tx on the swap.

BAD_INPUT not retryable

Arguments do not match the tool's input schema. Next: Fix the arguments using the input schema.

BAD_JSON not retryable

Request body is not valid JSON. Next: Send a JSON object.

TOO_LARGE not retryable

Request body over 64 KB. Next: Send less data.

BAD_AMOUNT not retryable

Amount is missing, zero or malformed. Next: Use human units, e.g. "1.5"; or amountIsBaseUnits=true for wei.

BAD_ADDRESS not retryable

An address is not a valid 0x address. Next: Pass a 20-byte 0x address.

BAD_PARAM not retryable

A parameter is out of range. Next: Read the hint and fix the parameter.

BAD_SLIPPAGE not retryable

slippageBps out of range. Next: Use 1..300.

BAD_DEADLINE not retryable

deadlineSeconds out of range. Next: Use 30..180.

BAD_HASH not retryable

Transaction hash is malformed. Next: Pass a 32-byte 0x hash.

BAD_DAY not retryable

dayId is not an integer UTC day. Next: dayId = floor(unixSeconds / 86400).

BAD_ACTION not retryable

Unknown action. Next: Use one of the enum values.

BAD_LIMIT not retryable

limitPrice malformed. Next: Pass a positive decimal string.

BAD_SLICES not retryable

slices out of range. Next: Use 2..48.

BAD_INTERVAL not retryable

intervalSeconds out of range. Next: Use 30..86400.

BAD_NAME not retryable

Wallet name is not allowed. Next: Letters, digits, - and _ only.

BAD_TOKEN_ID not retryable

NFT token id out of range. Next: Use a token id that exists.

UNKNOWN_TOOL not retryable

No tool with that name on this endpoint. Next: List tools with tools/list or GET /v1/tools.

UNKNOWN_TOKEN not retryable

Symbol not in the BlazarForce list or the KyberSwap verified list. Next: Pass the token's 0x address (any-token tools) or use blazar_tokens.

NOT_A_TOKEN not retryable

The address has no ERC-20 code (decimals() failed). Next: Check the address on polygonscan.

SAME_TOKEN not retryable

tokenIn and tokenOut are the same asset (POL and WPOL count as one). Next: Pick two different assets. Wrap/unwrap is not a trade.

SAME_ADDRESS not retryable

Sender and recipient are the same. Next: Use a different recipient.

UNKNOWN_CALLDATA not retryable

Calldata does not match a known ABI. Next: Only BlazarForce contract calls and ERC-20 approvals decode here.

UNKNOWN_TEMPLATE not retryable

No such deploy template. Next: See blazar_deploy_templates.

UNKNOWN_COLLECTION not retryable

Not a BlazarForce NFT collection. Next: See blazar_nft_collections.

TOKEN_ID_REQUIRED not retryable

tokenId is required here. Next: Pass tokenId or all=true.

OWNER_OR_TOKEN_REQUIRED not retryable

Pass owner or tokenId. Next: Pass one of them.

PAIR_REQUIRED not retryable

pair is required for source=pair. Next: Get a pair from blazar_pools.

NOT_A_BLAZAR_PAIR not retryable

Not a BlazarSwap pair. Next: Get a pair from blazar_pools.

SECRET_REJECTED not retryable

The request contained something that looks like a private key or seed. Next: Never send keys. Treat that key as compromised.

LOCAL_ONLY not retryable

Wallets are only created on the agent's own machine. Next: Use the SDK or the opt-in local tool.

NOT_FOUND not retryable

Unknown route. Next: MCP: POST /mcp. REST: GET /v1/tools.

NO_ROUTE not retryable

No route between these tokens on the allowed venues. Next: Try a hop token (WPOL, USDC) or blazar_any_quote for non-BZB pairs.

INSUFFICIENT_LIQUIDITY not retryable

Price impact is above the cap. Next: Trade smaller (see sizing) or raise maxPriceImpactBps.

PRICE_IMPACT_TOO_HIGH not retryable

Aggregator route loses more USD value than maxPriceImpactBps. Next: Trade smaller or raise maxPriceImpactBps.

USE_BLAZAR_ROUTE not retryable

BZB / BBY trades go through BlazarFeeRouter, not an outside aggregator. Next: Call blazar_build_swap: same safety guards, and it is the only route that earns BZB trading rewards.

TOKEN_UNSAFE not retryable

Token safety check failed (honeypot, blocked sells, or a very high transfer tax). Next: Do not trade it. See details.safety.

TOKEN_UNVERIFIED not retryable

Token is not on a verified list, or has caution flags. Next: Review details.safety with the user; rebuild with allowUnverified=true only if they accept the risk.

ROUTER_NOT_ALLOWED not retryable

The aggregator returned a target outside the router allowlist. Next: Do not sign. Report it.

CALLDATA_MISMATCH not retryable

Aggregator calldata failed a sanity check (recipient or value). Next: Do not sign. Rebuild once; if it repeats, use the other provider.

VENUE_NOT_ALLOWED not retryable

The fee router does not allow that venue. Next: Use blazar_quote routes only.

VALUE_MISMATCH not retryable

For POL input, value must equal amountIn. Next: Rebuild with the tool.

INSUFFICIENT_FUNDS not retryable

Not enough balance for value + gas. Next: Fund the wallet or trade smaller.

INSUFFICIENT_BALANCE_OR_ALLOWANCE not retryable

A token transfer failed: balance too low or approve not mined. Next: Send the approve step first, or fund the wallet.

REVERTED not retryable

The call reverted. Next: Read message; do not re-send unchanged.

INSUFFICIENT_STAKE not retryable

Less is staked than requested. Next: Withdraw at most the staked amount, or use exit.

NOTHING_STAKED not retryable

Nothing staked by this address. Next: Check staking info first.

BELOW_MIN_STAKE not retryable

Position would end below minStake. Next: Stake more, or withdraw everything.

NOT_A_REWARD_TOKEN not retryable

Not a listed reward token. Next: See blazar_staking_v2_info.rewardTokens.

NOTHING_TO_CLAIM not retryable

Nothing to claim. Next: Check claimable first.

CLAIM_WINDOW_CLOSED not retryable

Claim window for that day has passed. Next: Nothing to do.

DAY_NOT_POSTED retryable, after 3600000 ms

Winners for that day are not posted yet. Next: Check again after the UTC day ends and the owner posts it.

DAY_TOO_OLD not retryable

That day is outside the scan window. Next: Use a recent dayId.

NOT_DEPLOYED not retryable

Contract not deployed yet. Next: Wait for the owner to deploy; see blazar_overview.

PAUSED retryable, after 600000 ms

Contract paused by its owner. Next: Try later; check blazar_overview.

NOT_OWNER not retryable

Sender does not own this NFT. Next: Use the owner's address.

BURN_REFUSED not retryable

Transfer to a burn address refused. Next: Pick a real recipient.

WALLET_EXISTS not retryable

A wallet file with that name exists. Next: Pick a new name; files are never overwritten.

CHAIN_NOT_SUPPORTED not retryable

That chain is not supported for this tool. General tools support polygon (137, default), base (8453) and ethereum (1); BlazarForce tools (BZB, BlazarSwap, staking, rewards, fee router, NFTs, deploys) are Polygon only. Next: Pass chain: polygon, base or ethereum to a general tool, or omit chain for Polygon.
