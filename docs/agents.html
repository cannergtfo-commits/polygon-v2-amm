Manual setup

Add to ~/.cursor/mcp.json (VS Code: same block under "servers" with "type": "http").

{
  "mcpServers": {
    "blazar-polygon": { "url": "https://api.blazarforce.net/mcp" }
  }
}

Claude Code, or in Claude.ai / Desktop: Settings → Connectors → Add custom connector and paste the URL.

claude mcp add --transport http blazar-polygon https://api.blazarforce.net/mcp

ChatGPT: Plugins → + → Add custom MCP server, paste the URL, choose No authentication. Responses API:

{
  "type": "mcp",
  "server_label": "blazar_polygon",
  "server_url": "https://api.blazarforce.net/mcp",
  "require_approval": "never"
}

Grok app: grok.com/connectors → New Connector → Custom, paste the URL. xAI API (remote MCP tool):

curl https://api.x.ai/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $XAI_API_KEY" \
  -d '{
  "model": "grok-4.7",
  "input": [{"role": "user", "content": "What is BZB trading at on Polygon?"}],
  "tools": [{
    "type": "mcp",
    "server_url": "https://api.blazarforce.net/mcp",
    "server_label": "blazar_polygon"
  }]
}'

Every tool is also plain HTTPS. List them at /v1/tools; spec in openapi.json.

curl "https://api.blazarforce.net/v1/quote?tokenIn=POL&tokenOut=BZB&amount=10"
curl -X POST https://api.blazarforce.net/v1/tools/blazar_overview -d '{}'

✓ No tool signs. Builds are unsigned and simulated; nothing moves until your wallet signs. Never share a seed phrase or private key.
